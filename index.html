Proyecto en desarrollo

Facha Burgers

Plataforma web de pedidos y administración

Angular Node.js Express MongoDB UX/UI

Facha Burgers es una plataforma web diseñada para optimizar la gestión de pedidos e inventario de un restaurante. El sistema contempla una interfaz para clientes donde pueden consultar el menú y realizar pedidos, así como un panel administrativo para gestionar productos, ingredientes, existencias y órdenes. Actualmente, el proyecto continúa en desarrollo.
